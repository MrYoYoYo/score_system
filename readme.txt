班级点名系统

最低 Android 版本：Android 8.0（API 26）。目标版本：Android 16（API 36）。
默认教师账号：admin，初始密码：234512。支持自行注册教师和学生账号。

使用 SQLite 保存本机数据。
使用步骤：
1. 教师登录，在「课表」管理课程，添加当天包含当前时间的课表和教室。
2. 在「课表」管理学生及选课名单；也可退出后注册学生，在学生「课表」选择课程。
3. 教师在上课时间发起摇一摇签到，可选 5、10、15、30 分钟，最迟在下课时结束。
4. 从「我的」退出并登录学生账号，进入「考勤」中的摇一摇签到，握稳手机连续轻摇。
5. 教师可提前结束签到；超时未签到自动记为缺课。学生可查询个人记录并申请修改。
6. 教师在「考勤」审批申请或修改记录，在「统计」查看课程、学生、每堂课缺课情况。
